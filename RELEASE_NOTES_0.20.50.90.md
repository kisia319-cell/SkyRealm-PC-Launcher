# SkyRealm 0.20.50.90 — Studio mod publishing

- Removed the built-in FaerTestMod entry, Faer Sword item and automatic first-entry grant. The test mod is no longer preinstalled.
- Added launcher-to-game synchronization for locally published JavaScript and Python script mods.
- Opening the in-game mod catalog refreshes the list, including mods published while the game was already running.
- New mods appear under “Мои скриптовые моды” and remain disabled until enabled by the player.
- Re-publishing the same mod ID updates its source while preserving the in-game enabled state.
- No player movement or walking code was changed.
