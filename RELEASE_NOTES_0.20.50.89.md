# SkyRealm 0.20.50.89 — Studio mod publishing

- Removed the built-in FaerTestMod and automatic Faer Sword grant so mods can be tested through Studio's own publishing flow.
- Added launcher-to-game synchronization for locally published JavaScript and Python script mods.
- New mods appear in Catalog of Mods → My Script Mods and are disabled until enabled by the player.
- Re-publishing the same mod ID updates its source without resetting its enabled state.
- No player movement or walking code was changed.
