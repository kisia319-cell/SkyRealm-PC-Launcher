MICROSOFT WEBVIEW RUNTIME

pywebview uses the Windows WebView2 backend. The Evergreen WebView2 Runtime
is normally installed/updated separately by Microsoft; do not assume the
runtime files are bundled into SkyRealm.exe. Check the deployment model and
Microsoft terms for the final distribution:
https://learn.microsoft.com/microsoft-edge/webview2/concepts/distribution

RELEASE AUDIT NOTES

- Runtime packages are the packages used by the launcher and its imported
  modules. PyInstaller and its hooks are build tools, not application assets.
- The CI workflow records the exact installed package set in
  build-dependencies.txt and includes it in the portable release ZIP.
- Preserve the corresponding upstream license texts/notices when distributing
  these components. This file records package names, versions and license
  identifiers; verify the actual wheel license files before the Steam release.
- No third-party game audio, music, fonts, 3D models, textures or CDN-hosted
  JavaScript assets were identified in the inspected source tree as of
  2026-11-07.
- Historical EXE/ZIP binaries have not all been unpacked and independently
  inspected. This notice is not a blanket certification of every past build.
