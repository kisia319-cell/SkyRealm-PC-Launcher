# SkyRealm 0.20.50.87 — FaerTestMod

- Added the first built-in test mod, **FaerTestMod**, to the in-game mod catalog.
- Installing it enables the **Меч Файра** (Faer Sword), with 50 base damage.
- On the first entry into each single-player world, the mod grants and equips one sword and shows “Вы скачали мод FaerTestMod!”.
- The claim flag is stored in that world's save, preventing duplicate grants on later entries.
- Co-op worlds are excluded from the first test release.
- Player movement and walking code were not changed.
