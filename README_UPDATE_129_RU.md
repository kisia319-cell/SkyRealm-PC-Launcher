# SkyRealm Launcher 1.2.9 — полноценный календарь наград

- Кнопка «Календарь» теперь открывает полноценную страницу с календарём ежедневных наград.
- Показаны все дни текущего месяца, размер награды и состояние дня: получено, доступно, пропущено или ещё закрыто.
- Добавлена рабочая кнопка «Забрать награду за сегодня». Повторно получить награду в тот же день нельзя.
- Добавлен баланс жетонов календаря и счётчик последовательных дней входа.
- За каждые 7 дней подряд начисляется дополнительный бонус +50 жетонов.
- Состояние наград хранится отдельно для каждого аккаунта в постоянном профиле лаунчера на этом компьютере.
- Старый календарь игровых событий сохранён ниже ежедневных наград.
- Исправлена сборка EXE: в пакет теперь обязательно включаются `launcher-enhancements.js` и `launcher-enhancements.css`. Ранее сборочный скрипт пропускал эти файлы, из-за чего динамические страницы лаунчера могли не загружаться.

Важно: жетоны — внутренняя валюта календаря лаунчера; они пока не являются золотом или кристаллами игрового инвентаря и не синхронизируются с сервером.

Проверки: JavaScript синтаксис OK; Python синтаксис OK. Полная сборка EXE выполняется отдельно.
