# Автообновление SkyRealm — инструкция

## Как это работает
1. Лаунчер читает manifest.json из main.
2. Манифест содержит версию, ссылку на ZIP и SHA-256.
3. Лаунчер скачивает ZIP и сверяет SHA-256.
4. Встроенный SkyRealmUpdater.exe ждёт закрытия лаунчера, заменяет SkyRealm.exe и запускает новую версию.

## Текущие адреса
- Манифест: https://raw.githubusercontent.com/kisia319-cell/SkyRealm-PC-Launcher/main/manifest.json
- Архив релиза: https://github.com/kisia319-cell/SkyRealm-PC-Launcher/releases/latest/download/SkyRealm_Update.zip

## Важные требования
- В репозитории должны лежать исходники SkyRealm в корне, а не только README и workflow.
- updater_config.json должен быть включён в EXE сборку и содержать manifest_url выше.
- launcher_version.txt должен быть увеличен перед публикацией новой версии.
- ZIP релиза должен содержать SkyRealm.exe (не меньше 100 КБ) и launcher_version.txt с той же версией, что в манифесте.
- Не публикуйте пароль, токен или другие секреты в исходниках.

## Как опубликовать обновление
1. Обновить исходники и launcher_version.txt.
2. Запустить Actions → Build SkyRealm Windows Launcher → Run workflow, либо создать тег vX.Y.Z.
3. Дождаться зелёного завершения сборки.
4. Проверить Releases и открыть manifest.json. SHA-256 должен состоять из 64 hex-символов.
5. Проверить обновление на тестовой копии лаунчера, прежде чем распространять его пользователям.

## Текущий статус
Автообновление в исходном SkyRealm 0.9.4 уже реализовано: проверка манифеста, HTTPS, SHA-256 и отдельный helper для замены EXE. Публикация ещё не готова до переноса исходников в этот репозиторий и успешной сборки. Не считайте текущий пустой манифест опубликованным обновлением.
