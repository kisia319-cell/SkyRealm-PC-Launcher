# Автообновление SkyRealm — инструкция

## Автоматическое обновление игры
1. При нажатии «Играть» лаунчер проверяет `manifest.json` на GitHub.
2. Сверяет установленную версию игры с `game_version`.
3. Если вышла новая версия, скачивает `SkyRealm_Game.zip`, проверяет SHA-256 и версию внутри архива.
4. Распаковывает обновление во временную папку и заменяет игровые файлы. Если обновление не удалось, запускается уже установленная игра (или встроенная копия при первой установке).
5. Сохранения браузера остаются в локальном хранилище WebView, поскольку адрес и порт игры не меняются.

## Автоматическое обновление самого лаунчера
Лаунчер также проверяет номер версии при старте и скачивает `SkyRealm_Update.zip`, если опубликована более новая версия.

## Адреса
- Манифест: https://raw.githubusercontent.com/kisia319-cell/SkyRealm-PC-Launcher/main/manifest.json
- Архив лаунчера: https://github.com/kisia319-cell/SkyRealm-PC-Launcher/releases/latest/download/SkyRealm_Update.zip
- Архив игры: https://github.com/kisia319-cell/SkyRealm-PC-Launcher/releases/latest/download/SkyRealm_Game.zip

## Как опубликовать обновление
1. Измени файлы игры в каталоге `game/` и обязательно увеличь `game/version.txt` (например, с `0.9.2` на `0.9.3`).
2. Если изменился код лаунчера, увеличь `launcher_version.txt`.
3. Отправь изменения в `main`. GitHub Actions соберёт EXE, создаст ZIP игры и лаунчера, посчитает SHA-256 и обновит манифест.
4. Проверь вкладку Actions: сборка должна завершиться успешно. Затем проверь Releases и `manifest.json`.

Обновления игры и лаунчера распространяются через публичные GitHub Releases. Токены и пароли не нужны.
