# SkyRealm 0.20.50.115 — Сохранение прогресса артефактов

- Исправлена изоляция эволюции артефактов между мирами: при загрузке каждого мира прогресс сначала сбрасывается, затем восстанавливается только из его собственного сохранения.
- Это предотвращает перенос уровня артефакта, перезарядки спасения и временных усилений из одного мира в другой.
- Добавлен регрессионный тест для загрузки и переключения миров.
- Предыдущие изменения артефактов и комплектов сохранены; код передвижения не затрагивался.
