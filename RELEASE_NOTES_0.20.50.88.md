# SkyRealm 0.20.50.88

## Мир боссов
- Каждое существо получает собственную ограниченную территорию.
- Добавлены тематические разрушенные музеи и святилища для разных типов существ.
- По мере получения урона существом его музей визуально разрушается: колонны ломаются, появляются трещины и обломки.
- Добавлены пульсация рун и светящиеся детали.

## Питомцы
- Усилен урон команды атаки питомца на 35%; верхний предел увеличен до 350.

## Совместимость
- Код перемещения игрока не изменялся.
- Сборка и тесты должны быть проверены GitHub Actions после коммитов.
