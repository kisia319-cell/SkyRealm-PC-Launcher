# PrimeLauncher 1.2.79

- Expanded launcher settings with automatic update checks and update-popup preferences.
- Added optional automatic world backup before a game update; an unexpected backup error stops the update instead of proceeding without the requested safety copy.
- Added exit confirmation and optional last-section restore.
- Added portable JSON settings export/import and a safe reset to defaults.
- Settings reset leaves player accounts, world saves, calendar entries and backup archives untouched.
- Fixed native text-scale validation so the 130% option is retained.
- Existing diagnostics, repair, rollback, cloud backups, performance profiles and game controls remain available.
