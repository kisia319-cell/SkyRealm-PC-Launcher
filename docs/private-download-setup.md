# Закрытая загрузка SkyRealm

## Что уже подготовлено

- В проекте Supabase `skyrealm-auth-prod` создан приватный Storage bucket: `skyrealm-downloads`.
- Bucket закрытый (`public = false`), максимальный размер одного файла — 512 MiB.
- Разрешены ZIP и исполняемые файлы Windows.
- Платёжный сервис и выдача ссылок ещё НЕ подключены.

## Важно: релиз GitHub пока публичный

Файлы в публичном GitHub Release `v1.0.0` доступны по прямым ссылкам, в том числе `SkyRealm.exe` и `SkyRealm_Game.zip`. Создание приватного bucket не закрывает эти старые ссылки. Не рекламируйте сборку как платную и защищённую, пока файлы не перенесены и публичные копии не удалены или не сделаны приватными.

## Следующие шаги

1. Откройте Supabase Dashboard и выберите проект `skyrealm-auth-prod`.
2. Перейдите в **Storage** → bucket `skyrealm-downloads`.
3. Загрузите туда проверенные файлы релиза. Не загружайте секреты, ключи или данные покупателей.
4. Проверьте, что bucket остаётся **Private**. Не включайте публичный доступ и не создавайте публичные ссылки.
5. Перед удалением публичных GitHub assets сохраните резервную копию файлов в надёжном месте. Затем удалите публичные assets/release через GitHub, если хотите, чтобы старые прямые ссылки перестали работать.
6. Только после переноса можно создать отдельную серверную Edge Function для генерации временной подписанной ссылки. Она должна проверять подтверждённый платёж на сервере и выдавать короткоживущую ссылку. Не доверяйте параметрам оплаты, присланным браузером.
7. Секреты платёжного провайдера и серверный ключ Supabase храните только в secrets/environment variables Edge Function. Никогда не добавляйте их в `docs/index.html`, GitHub Pages или публичный репозиторий.
8. До настройки провайдера и серверных секретов кнопка оплаты на сайте должна оставаться отключённой.

## Ограничение

Пока нет платёжных секретов и подтверждённого аккаунта платёжного провайдера, автоматическая оплата не работает. Приватный bucket сейчас пуст и сам по себе не защищает файлы, которые опубликованы в GitHub Release.
