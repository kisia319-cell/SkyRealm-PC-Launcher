# Настройка оплаты SkyRealm для самозанятого

Статус: подготовка. Приём денег на сайте не включён.

## Выбранный вариант для проверки
ЮKassa для самозанятых. Официальная инструкция и условия:
- https://yookassa.ru/recipes/press-center/ehkvajring-dlya-samozanyatyh/
- https://yookassa.ru/docs/support/payments/conditions

ЮKassa указывает, что самозанятому нужно зарегистрироваться как плательщик НПД, создать идентифицированный кошелёк ЮMoney, подать заявку на ЮKassa для самозанятых и дождаться инструкций. Подключение и допустимость конкретного цифрового продукта подтверждает сам платёжный сервис.

## Что должен сделать владелец
1. Убедиться в приложении/веб-кабинете «Мой налог», что статус НПД активен.
2. Создать и идентифицировать кошелёк ЮMoney на своё имя.
3. Подать заявку на ЮKassa для самозанятых: https://yookassa.ru/
4. Описать продукт честно: цифровая компьютерная игра SkyRealm, собственная разработка, цена 199 ₽, доставка цифровой загрузки после подтверждения оплаты.
5. Дождаться одобрения, подписать договор и получить инструкции/доступы для интеграции.
6. Не отправлять секретные ключи в чат и не вставлять их в HTML или публичный GitHub-репозиторий.

## Что требуется для технического запуска
- Серверный endpoint создаёт платёж на стороне ЮKassa и возвращает покупателю только платёжный URL.
- Сервер проверяет уведомление от провайдера и сверяет статус, сумму 199 RUB и идентификатор заказа.
- Ссылка на скачивание выдаётся только после подтверждённого платежа. Страница возврата из платёжной формы сама по себе не является доказательством оплаты.
- Файл игры хранится в приватном хранилище, а ссылки на скачивание имеют ограниченный срок действия.
- Для каждого платежа самозанятый формирует чек в «Мой налог» в соответствии с правилами НПД.
- Перед стартом добавить контакты продавца, описание лицензии/условий использования, политику конфиденциальности, правила возврата и необходимые сведения о продавце.

## Важно
GitHub Pages — статический хостинг; секретные ключи и серверную проверку оплаты нельзя размещать в клиентском JavaScript. До одобрения платёжного сервиса и завершения серверной интеграции кнопка покупки должна оставаться отключённой.
