# SkyRealm 0.20.50.159 — Питомцы-компаньоны

- Лесных животных теперь можно приручить: покорми одного зверя лесными ягодами три раза, соблюдая паузу в три игровых дня между кормлениями.
- После приручения зверь становится постоянным спутником в текущем мире и следует за игроком с плавным движением.
- У спутника появляется заметный ошейник со свечением и подпись «КОМПАНЬОН».
- Спутник приносит свой видовой подарок; повторный подарок доступен раз в два игровых дня.
- Приручение и время подарков сохраняются в мире и переживают перезапуск.
- Одновременно можно иметь одного лесного спутника. Остальные животные продолжают жить и перемещаться самостоятельно.
- Код ходьбы, прыжков, физики и управления игроком не менялся.
