# SkyRealm 0.20.50.182

## Мобильное управление
- Добавлена отдельная экранная кнопка «Действие», которая вызывает штатное взаимодействие клавишей E: двери, предметы, терминалы, сундуки и NPC.
- Добавлена экранная кнопка «Назад»: сначала закрывает верхнее открытое окно штатной логикой Escape, затем использует кнопку закрытия панели, если у неё нет Escape-обработчика.
- Кнопки адаптируются к вырезам экрана и безопасным отступам телефона.
- На ПК с обычным указателем мобильные кнопки не отображаются.
- Код ходьбы, джойстика и обработки движения не изменялся.
