
# SkyRealm Game Asset Register

This file accompanies the game-only archive. It covers the inspected game source tree, not every historical executable or user-created mod.

- Game source: JavaScript, HTML and CSS in this folder.
- Sound: Web Audio API procedural synthesis; no separate WAV/MP3/OGG files were found in the source tree.
- Fonts: system font stack; no bundled TTF/OTF/WOFF/WOFF2 font files found.
- Models/textures: no standalone GLB/GLTF/OBJ/FBX model or texture packages found; game visuals are primarily drawn/generated by code.
- Logo: `skyrealm-logo.svg`, an SVG asset with vector paths, gradients and glow filter.
- Not audited: historical ZIP contents, user mods, and provenance of binary assets stored outside this game folder.

This is a technical inventory, not legal advice or a guarantee of rights clearance. Verify every final release archive and every user-added mod before commercial distribution.
