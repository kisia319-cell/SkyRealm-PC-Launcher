# SkyRealm Game 0.20.50.160

## Follow-up visual repair
- Removed the remaining per-tile colour changes that made terrain look like a checkerboard. Each biome now uses a continuous shared base colour with richer grass clumps, stones, snow glints, desert grains and volcanic cracks.
- Added a guaranteed decorative valley hamlet with five detailed houses, a small garden, well, barrels, lanterns, paths and a ring of trees. This appears in older worlds too, even if their original nearby trees were chopped or the save has no settlement data.
- Corrected the visual scaling so the player is larger and NPCs retain their intended scale.
- Player face, eyes, arms and clothing details remain visible.

## Safety
- The hamlet and its trees are decorative only: no collision, harvesting, inventory, world-save or movement changes.
- WASD, walking, collision and physics remain unchanged.
- Existing saves remain compatible; no world reset is required.
